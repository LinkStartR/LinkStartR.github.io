密度怎样变成概率

只做一段均匀范围的计算，记住“高度不是总量”。

  1. 范围从 0 到 0.5，宽度为 0.5；密度在这整段都等于 2。
  2. 这一段的概率 = 密度 × 范围宽度，所以是 2 × 0.5 = 1。
  3. 如果只看 0 到 0.25，概率为 2 × 0.25 = 0.5。

你要带走的逻辑：连续数值的概率属于一段范围；密度可以超过 1。

下界与真实评分的差距

这是关系解释，不做高维积分；你只要知道扣掉了什么。

符号它在这里的意思
x已经观察到的数据
z没有直接观察到的隐藏变量
p(x)模型赋给观察数据的概率或密度
log对数刻度，保留正数大小顺序
q(z|x)看到数据后，用来猜隐藏变量的方便规则
p(z|x)模型中看到数据后隐藏变量的实际条件分布
ELBO可计算的变分下界评分
KL(A || B)按分布 A 加权检查分布 B 的差异，非负且通常不对称
|已知右侧条件的意思
  1. 固定一份观察数据 x，模型给它的对数似然记作 log p(x)。
  2. 用一个方便计算的隐藏变量猜测 q(z|x)，构造一个可算评分 ELBO。
  3. 关系是 log p(x) = ELBO + KL(q(z|x) || p(z|x))。
  4. KL 项非负，所以 ELBO 不高于 log p(x)；猜测越贴近模型的真实解释，差距越小。

你要带走的逻辑：下界是保守评分；提高它时，也要注意它与真实评分的差距。

加噪为什么能直接跳到一个阶段

把标准形式放在这里，正文只记“累计保留 + 合并噪声”。

符号它在这里的意思
x_0最初的干净数据
t选中的噪声阶段
x_t第 t 阶段的污染数据
a_t从起点累计到 t 的信息保留比例，位于 0 与 1 之间
ε独立抽取的标准高斯噪声：以 0 为中心、呈钟形分布且使用固定统计刻度的随机扰动
√开平方，使该系数平方后等于根号内的数
·乘法
1 − a_t对应阶段需要补入的噪声比例
  1. 标准构造可写成 x_t = √a_t · x_0 + √(1 − a_t) · ε。
  2. 先计算累计保留比例 a_t；它把之前各步保留的信息合到一个数里。
  3. 再独立抽一份按固定规则产生的噪声 ε，把它按当前阶段的强度加入。
  4. 不必逐步模拟前向过程，就能造出第 t 阶段的输入。这里的平方根是为了匹配噪声强弱的统计刻度。

你要带走的逻辑：闭式加噪省的是造训练输入的过程，不是把生成过程自动缩成一步。

直线路径的方向答案

只看一个数值位置，方向不随时间改变。

符号它在这里的意思
x_0噪声起点
x_1抽到的真实数据终点
t从 0 到 1 的路径时间
x_t时间 t 的示范位置
·乘法
  1. 设起点 x_0 = 0，终点 x_1 = 2，时间 t 从 0 走到 1。
  2. 中间位置写成 x_t = (1 − t) · x_0 + t · x_1。
  3. 时间一半时位置在 1；沿这条示范路，每单位时间的移动量始终是 x_1 − x_0 = 2。
  4. 模型训练时见到中途位置和时间，学习预测这个已知方向；真正生成时没有把终点答案偷偷交给模型。

你要带走的逻辑：固定点对可以造方向答案；这个答案简单，不代表整体分布配对已经最优。
