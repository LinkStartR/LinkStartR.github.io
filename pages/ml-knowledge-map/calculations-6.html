奖励与回报的两步账本

只算两步，看看即时正分怎样变成负总账。

符号它在这里的意思
0.5折扣因子，即未来每远一步的权重乘一半
  1. 第一步奖励是 2，第二步奖励是 −3。
  2. 不折扣时回报是 2 + (−3) = −1。
  3. 若下一步按一半折扣，回报是 2 + 0.5 × (−3) = 0.5。
  4. 两种评价不一样，是因为你改变了对未来的重视程度；不是第二步的实际奖励变了。

你要带走的逻辑：奖励是即时反馈，回报是按选定规则合起来的后续总账。

0.9 与 0.99 的粗略耐心尺度

这只是长期权重累计的直觉尺度，不是到了这个步数就忽略未来。

符号它在这里的意思
γ折扣因子
1 / (1 − γ)无限长几何权重的累计值，也常被用作粗略时间尺度
≤、<分别表示不大于、小于
  1. 折扣每远一步乘一次 γ，γ 是折扣因子。
  2. 若每步都得到 1，无限累计的权重总和是 1 / (1 − γ)，前提是 0 ≤ γ < 1。
  3. γ = 0.9 时，这个尺度是 10；γ = 0.99 时是 100。
  4. 它说明后者给远期留的总权重大得多；不是硬性的 10 步或 100 步截止线。

你要带走的逻辑：更耐心意味着更多远期后果要估，不自动意味着表现更好。

Q 学习的一步目标

只看一个旧状态和一个新状态，不把整个网络手算一遍。

符号它在这里的意思
s执行动作前的状态
a在状态 s 执行的动作
r这一步实际收到的奖励
s′随后到达的新状态，撇号表示后一个状态
a′新状态中的候选动作
Q(s′, a′)新状态里候选动作的预计回报
max从所有候选评分中取最高值
γ折扣因子
y这次用来更新 Q 的目标
  1. 旧状态选定动作 a，得到奖励 r，随后来到新状态 s′。
  2. 新状态有两个动作，评分是 0 和 2；最高评分取 2。
  3. 若 r = 0、折扣 γ = 0.5，新目标 y = r + γ × max Q(s′, a′)，所以 y = 1。
  4. 旧状态动作的 Q 评分向这个目标靠近；不是把整条未来道路都重新走了一遍。

你要带走的逻辑：目标的未来部分来自估值，可能有误差；真正终止时去掉未来项。

对数概率为什么进入策略梯度

看一个数学改写怎样让采样帮你估梯度，不做长串数值运算。

符号它在这里的意思
θ策略中可学习的参数
a动作
pθ(a)该动作在当前策略下的选择概率，这里省略状态输入
R(a)行动带来的成绩，完整任务中对应后续回报
J要提高的平均回报目标
∇对参数求梯度
log对数刻度
×乘法
  1. 设 pθ(a) 是参数 θ 的策略选择动作 a 的概率，R(a) 是这个动作之后的成绩。
  2. 目标 J 是按策略选择概率加权的平均成绩：每个动作贡献 pθ(a) × R(a)。
  3. 对正概率可用 ∇pθ(a) = pθ(a) × ∇log pθ(a)。这只是对数求导关系的改写。
  4. 因此你能按 pθ 抽动作，再用成绩或减基线后的优势，乘上对数概率的梯度，估计目标的梯度。
  5. 整条轨迹情形还要处理多个时刻与后续成绩；采样带来的噪声没有因为这个恒等式消失。

你要带走的逻辑：对数来自“变化的采样概率如何求导”，不是仅仅因为动作概率总和为 1。

重要性权重不是加倍奖励

只比较一个动作的新旧概率。

符号它在这里的意思
ρ概率比，即这条经历的重加权系数
π新、π旧新的动作选择规则、采集这条经历时的旧规则
a已采到的动作
s当时的状态
a|s在已知状态 s 的条件下选动作 a
/除法
  1. 旧策略给动作 a 的概率是一半，新策略给它的概率是 1。
  2. 概率比 ρ = π新(a|s) / π旧(a|s)，所以 ρ = 2。
  3. 这条旧经历在估计新规则平均时被赋更大权重；经历中真实获得的奖励没有改写。
  4. 如果旧策略概率为 0，就没有这类经历，不能靠除法凭空补出数据。

你要带走的逻辑：旧数据复用必须有覆盖，还要防止极大权重放大噪声。

每步 99% 准，长串行动仍可能至少错一次

这是一个独立错误的直觉模型；真实分布漂移可能更复杂。

符号它在这里的意思
0.99假设的每一步正确概率
100假设的一串行动步数
¹⁰⁰将前面的数连乘 100 次
1 − 0.99¹⁰⁰全部正确事件的反面，即至少有一步出错
≈约等于
  1. 先假设每一步正确概率都是 0.99，而且各步错误彼此独立。
  2. 连续 100 步全部正确的概率是 0.99¹⁰⁰，约为 0.37。
  3. 至少错一次的概率就是 1 − 0.99¹⁰⁰，约为 0.63，也就是约 63%。
  4. 这只说明长串行动会累积出错机会；63% 不是某个模仿模型的实验结果，也不能直接当成复合损失的增长规律。
  5. 真实模仿里，一次错还可能改变后续状态，使后面不再保持原来的 99% 正确率。

你要带走的逻辑：独立误差的累计已经值得警惕；因动作改变输入造成的复合误差还要另行处理。
