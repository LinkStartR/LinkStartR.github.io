动量：一条递推，六个读法Adam：为什么第一步大小近似等于基础学习率归一化：同一算式，为什么伙伴不同会改变结果

动量：一条递推，六个读法

这里只用一个参数和两次梯度。算式用于解释记忆怎样产生，不要求你照着长链手算。

符号它在这里的意思
t当前第几步
g_t当前梯度
m_t按平均写法保存的方向记忆
u_t按累加写法保存的方向记忆
β保留旧历史的比例，取 0 到 1 之间
θ_t当前参数
α学习率
  1. 平均写法是 mₜ = βmₜ₋₁ + (1−β)gₜ，然后 θₜ = θₜ₋₁ − αmₜ。先混合方向，再更新参数。
  2. 侧面一，递推：每一步只需要旧记忆与当前梯度，不需保存全部历史。
  3. 侧面二，展开：一次旧记忆再被保留，会让较早梯度多乘一次 β；这就是历史逐渐变淡。
  4. 侧面三，记忆长度：β 接近 1 时，约 1/(1−β) 步是常用尺度，但历史没有硬截止。
  5. 侧面四，记账尺度：若改成 uₜ = βuₜ₋₁ + gₜ，持续恒定的梯度在稳定后被放大到 1/(1−β) 倍；平均写法没有这层放大。
  6. 侧面五，稳与快：换向的梯度互相抵消，连续同向的梯度保留；是否额外加速还取决于学习率与记账约定。
  7. 侧面六，滞后与边界：新方向出现时，旧记忆不会立刻清空，所以谷底附近可能过冲。
  8. 最小检查：β=0.5，初始记忆为 0，两次梯度都是 2。平均写法的记忆先到 1、再到 1.5；累加写法先到 2、再到 3。按对应比例调整学习率，两种参数步子可以相同。

你要带走的逻辑：看到“动量放大了几倍”时，先看它每步加入的是完整梯度，还是按剩余比例加入的梯度。

Adam：为什么第一步大小近似等于基础学习率

只检查一个参数的第一步，避免把很多参数的小数排成表。

符号它在这里的意思
t当前第几步
g_t当前梯度
m_t方向的未修正记忆
v_t平方大小的未修正记忆
β₁、β₂分别保留两份旧记忆的比例
m̂_t、v̂_t补偿起步空白后的两份记忆
θ_t当前参数
α基础学习率
ε分母中防止除零的很小正数
√开平方
|g_t|忽略正负号后的梯度大小
  1. 两份记忆从 0 开始。方向记忆 mₜ = β₁mₜ₋₁ + (1−β₁)gₜ；尺度记忆 vₜ = β₂vₜ₋₁ + (1−β₂)gₜ²。
  2. 把方向记忆除以 1−β₁ᵗ，把尺度记忆除以 1−β₂ᵗ，得到修正后的 m̂_t 与 v̂_t。这里的除数是已经积累的总权重。
  3. 参数更新是 θₜ = θₜ₋₁ − αm̂ₜ/(√v̂ₜ + ε)。先确定方向，再按尺度换算步长。
  4. 第一次的修正方向恰是 g₁，修正尺度恰是 g₁²，所以这次变化大小为 α|g₁|/(|g₁|+ε)。
  5. 当梯度非零，并忽略 ε 时，分子与分母抵消，大小就是 α；梯度的正负决定朝哪边。若梯度为 0，第一步是 0，不能使用同样的抵消。
  6. 最小检查：梯度为 2、α=0.1，忽略 ε 后第一步大小是 0.1。把梯度换成 1，大小仍是 0.1；换成 0，则不动。

你要带走的逻辑：第一步的性质有条件；实际实现里的防除零小数和零梯度都必须算在边界内。

归一化：同一算式，为什么伙伴不同会改变结果

只用 1、3 这一组数，观察统计范围，不把不同归一化拆成一长串手算。

符号它在这里的意思
x归一化前的一个数
μ所选这组数的平均值
σ²与平均的距离平方的平均，即这组数的散开程度
ε避免除零的很小正数
x̂统一中心与刻度后的数
γ可学习的缩放参数
β可学习的移动参数，不是动量保留比例
y最终输出
√开平方
  1. 先计算这一组的平均 μ，再看各数与平均的距离平方的平均 σ²；σ² 表示这组数散开的程度。
  2. 中心操作是 x̂ = (x−μ)/√(σ²+ε)，然后 y = γx̂+β。每个输入先对齐中心、再对齐刻度，最后由两个可学习旋钮微调。
  3. 1、3 的平均是 2，两个距离分别为 −1 和 1，散开程度是 1。忽略小数 ε 时，归一化结果为 −1、1。
  4. 关键不是继续算更多数，而是问这组数从哪来：BatchNorm 借同批对应值，LayerNorm 从样本内部取数。
  5. 若这一组的数全部相同，散开程度为 0；保留 ε 才能避免除以 0。

你要带走的逻辑：归一化的名称差异，往往首先来自“用哪一组数计算平均和散开程度”。
